# 微信 PC 机器人方案选型踩坑记录

本文记录 2026-10 在 Windows 上做微信机器人时对各路方案的实际验证结果，供后来者少走弯路。

## 结论速览

| 方案 | 微信版本 | 结果 | 原因 |
| --- | --- | --- | --- |
| ntchat（DLL 注入） | 3.6.0.18 | ❌ | 该版本被服务端禁止登录 |
| 改 DLL 版本号伪装 | 3.6.0.18 | ❌ | 触发客户端文件自校验，20 秒内崩溃 |
| 改内存版本号 | 3.6.0.18 | ❌ | 进程内存中没有独立版本号字段 |
| wxauto（UIAutomation） | 3.9.x | ❌ | 3.9.x 现在也被低版本拦截；且项目 2025-10 归档 |
| wxauto | 4.1.12+ | ❌ | Qt 自绘，无障碍节点消失 |
| **本地 DB 解密 + 界面驱动** | **4.1.12+** | ✅ | 不依赖界面结构 |

## 1. ntchat 路线为什么必死

`chatgpt-on-wechat-win` 用的是 ntchat，只能注入微信 3.6.0.18。但腾讯服务端会校验客户端上报的版本号，3.6 系列直接拦登录。

圈内流传的解法是改客户端里的版本号字符串。实测结论：**不可行**。

- 扫描发现 `WeChatWin.dll`（约 39MB）中只有 1 处明文 `3.6.0.18`，`improve.xml` 中 1 处
- 用等长替换改成 `3.9.5.81`（同为 7 字节，文件大小和代码偏移完全不变，不影响注入逻辑）
- 对照实验：
  - 未打补丁 → 微信稳定运行
  - 打补丁后 → **20 秒内必然崩溃退出**
- 结论：这版微信带文件完整性自校验，改文件必挂

> 过程中有个坑值得注意：早先误以为"启动后自动退出"是补丁导致，实为 shell 后台启动的子进程被回收。
> 正确的分离启动方式是 `cmd //c "start WeChat.exe"`，否则会得到完全相反的结论。

既然不能改文件，退而求其次改内存（Cheat Engine 那套思路）。全进程内存扫描结果：

- ASCII 明文、UTF-16、数字 DWORD（`0x63060012`）三种形式全查
- 命中的 `3.6.0.18` **全部**是安装路径里的目录名（`C:\...\Tencent\WeChat\[3.6.0.18]\...`）
- 排除路径上下文后，独立版本号字段**一处都没有**

也就是说那处字符串根本不是上报版本号用的，只是路径模板，改它只会触发自校验。此路彻底断掉。

## 2. wxauto 路线为什么也不行

wxauto 基于 Windows UIAutomation 遍历控件树，在 3.9.x 上工作良好。两个问题：

1. **版本**：原本指望 3.9.12.57 能正常登录，实测仍然提示"版本过低"——3.x 系列现在整体被拦
2. **架构**：就算能登录，微信 4.x 把聊天区改成 Qt 自绘（窗口类 `MMUIRenderSubWindow*`），对 UIA / MSAA 完全不暴露无障碍节点，控件树里连输入框和消息列表都找不到。作者因此在 2025-10-28 归档停更

顺带一提，wxauto 已从 PyPI 下架，需要直接从 GitHub 装源码。

## 3. 最终方案：绕开界面结构

[wechatauto-replica](https://github.com/fanyuantaier/wechatauto-replica) 的思路是**把读和写拆开**：

- **读消息**：解密微信本地 SQLite 数据库（SQLCipher 4）。密钥通过只读方式扫描 `Weixin.exe` 进程内存获得，用 SQLCipher 的 HMAC 规则校验正确性。数据目录在 `xwechat_files\<wxid>\db_storage\`
- **发消息**：向 `Weixin.dll` 写入一个字节，热激活其内部的 Qt accessibility gate 恢复 UIA 树；UIA 优先，失败时用 OCR + 坐标兜底

由于读取完全不依赖界面渲染，微信改 UI 不影响读消息。这也意味着没有了自校验崩溃问题。

### 已知代价

- 发送仍是 GUI 操作，桌面锁屏时无法工作
- 需要读进程内存，可能被安全软件拦截（Doctor 会给出诊断）
- 必须 64 位 Python

## 4. 安装包的坑

从 GitHub 下大文件时用 `-C -` 断点续传要小心：两次中断续传会把分段**拼接成坏文件**，安装时报"文件完整性有问题"。

建议：

- 优先用腾讯官方 CDN，速度快得多
  - `https://dldir1v6.qq.com/weixin/Universal/Windows/WeChatWin_4.1.15.exe`
- 下载后务必校验 SHA256
- 若要交叉验证，从两个不同的 CDN 域名各下一次比对哈希即可，比拿第三方站点的哈希值可靠

> 实测第三方版本索引站记录的哈希属于另一渠道，与官方 CDN 下载的文件对不上，别拿它当基准。
